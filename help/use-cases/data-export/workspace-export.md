# Workspace导出

本文概述如何使用Analysis Workspace导出选项实施以下[数据导出用例](overview.md)：

- 临时和定期报表

## 简介

通过直接从Analysis Workspace导出数据，个人用户无需设置云目标或数据管道，即可下载项目或通过电子邮件发送项目。

## 更多信息

您可以从Analysis Workspace以PDF、CSV或JSON文件的形式将项目或项目的一部分下载到您的工作站。 下载仅限临时性的，限制为50,000行。 有关详细信息，请参阅[下载到您的工作站](/help/analysis-workspace/export/download-send.md)。

您还可以通过电子邮件将项目发送给组织中的其他用户（临时或按计划）。 通过电子邮件发送的报表限制为400行。 有关详细信息，请参阅[发送给其他用户](/help/analysis-workspace/export/t-schedule-report.md)。

要比较所有Analysis Workspace导出方法，包括将完整表导出到云，请参阅[导出概述](/help/analysis-workspace/export/export-project-overview.md)。
