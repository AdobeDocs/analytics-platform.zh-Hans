# 使用同事的产品内体验

{{release-limited-testing}}

Co-worker的产品内体验位于Analysis Workspace右侧的聊天面板中。 同事使用打开的项目作为上下文，因此您可以询问有关分析的问题或让同事构建项目，而无需解释其中包含的内容。

## 了解Workspace中的同事

### 先决条件

* 已为您的组织启用&#x200B;**协同工作**：默认情况下禁用协同工作的产品内体验。 Customer Journey Analytics管理员必须先为组织启用此项，用户才能访问它。

  如果您无法访问Workspace中的同事，请联系您的管理员。 有关详细信息，请参阅[IMS组织首选项](/help/analysis-workspace/user-preferences.md#ims-organization-preferences)。<!-- need to update this section with the new toggle -->

<!-- FOLLOW-UP: Coworker permissions are still being finalized. The Coworker permission name below is a placeholder. Confirm the name, category, and Admin Console steps with the SME. -->

* **权限**：在[!UICONTROL Adobe Admin Console]中，[!UICONTROL 报告工具] **[!UICONTROL 辅助进程]**&#x200B;权限决定了辅助进程的访问权限。 [产品配置文件管理员](https://helpx.adobe.com/cn/enterprise/using/manage-product-profiles.html)必须将此权限添加到您的产品配置文件。 有关详细信息，请参阅[访问控制](/help/technotes/access-control.md#access-control)。

* **数据视图访问**：同事使用您现有的Analysis Workspace和数据视图权限。 它无法访问您尚无法访问的数据或组件。

### 在Workspace中的同事和同事应用程序之间进行选择

同事的产品内体验具有许多与[CX Enterprise Coworker应用程序](https://experienceleague.adobe.com/zh-hans/docs/coworker/content/chat/use-cases/data-insights/analytics-chat)相同的功能，包括您有权访问的技能。 但是，在决定何时可以使用一种方式而不是使用另一种方式时，存在一些重要差异：

| | 同事的产品内体验 | 同事应用程序 |
| --- | --- | --- |
| **何时使用** | 要构建计划保留、与其他用户共享或随时间更新的项目。 | 你想得到一个快速的答案。 如果需要，您可以选择稍后将分析转换为Workspace项目。 |
| **上下文** | 以项目为中心<p>使用打开的Workspace项目作为起点。 您可以引用并构建项目中已存在的面板、表格和组件。</p> | 以数据视图为中心<p>使用您有权访问的数据视图或您在Co-worker内存中设置为首选项的数据视图。 您可以在提示中描述要分析的内容。</p> |
| **典型用户** | 在Workspace中构建并验证分析的分析人员。 | 需要答案而不需要访问或学习Workspace的业务用户。 |
| **输出** | 同事可将面板、表格和组件直接添加到Workspace项目。 <p>在适当的时候，它也会在聊天中回答。</p> | 对话中提供答案和分析，并可选择在Analysis Workspace中打开。 |

### 与同事一起可以做什么

#### 询问有关打开项目的问题

您可以向同事提问，例如：

* 总结项目。
* 查找数据中的见解并标记异常。
* 对面板运行根本原因分析。
* 解释如何在Analysis Workspace中执行一些操作，例如如何添加折线图或如何根据表单元格的值对其进行着色。
* 解释组件，例如量度或维度。

有关详细信息，请参阅[询问有关项目的问题](#ask-questions-about-a-project)。

#### 生成并编辑打开的项目

您可以要求同事执行以下操作：

* 创建一个具有您指定的维度、量度和日期范围的自由格式面板。
* 在项目中添加面板。 同事添加新的面板，而不覆盖现有面板。
* 划分表格或添加比较列。
* 更改面板的日期范围或可视化图表类型，例如将表格更改为折线图。
* 重命名面板。
* 按名称应用现有区段，从纯语言描述创建区段，或复制区段并更改其逻辑。
* 创建日期范围和简单计算量度。
* 添加描述或包含项目见解的文本可视化图表。
* 创建具有多个面板的项目，或复制项目并适应不同的受众或区域。
* 保存该项目。

有关详细信息，请参阅[更新项目](#update-a-project)。

### 当同事在聊天中更新项目或回答时

同事根据您询问的内容决定是在聊天面板中应答还是更改项目。 有关详细信息，请参阅[更新项目](#update-a-project)和[询问有关项目的问题](#ask-questions-about-a-project)。

您还可以明确说明您希望同事做什么。 例如，您可以在聊天中使用&#x200B;_之类的短语_&#x200B;或&#x200B;_只告诉我_&#x200B;在聊天面板中获取答案，或在此表&#x200B;_中使用诸如_&#x200B;添加到项目&#x200B;_或_&#x200B;之类的短语来更新项目。

## 在项目中使用同事

同事可以查看打开项目中的每个面板和表格。 您可以要求同事回答有关项目的问题或帮助您更新项目。

>[!TIP]
>
>您可以随时中断同事或更新项目：
>
>* **引导或停止任务**：当同事工作时，按&#x200B;**Shift+Enter**&#x200B;以赋予任务更多方向，或按&#x200B;**Esc**&#x200B;以停止任务。
>
>* **在Workspace中更新项目**：如果在同事工作期间编辑项目，则同事可以识别您所做的更改。

### 更新项目

当您要求同事在项目中构建或编辑某些内容时，同事将相应地更新项目。 这包括以&#x200B;_add_、_create_、_edit_、_break_、_change_&#x200B;和&#x200B;_compare_&#x200B;等词开头的请求。 例如，您可以要求Co-worker添加面板和表格、划分数据或创建区段。

1. 在Customer Journey Analytics中，打开现有的Workspace项目或创建新项目。

1. 选择标题右上角的&#x200B;**同事**&#x200B;图标![询问同事](/help/assets/icons/coworker.svg)以打开同事聊天面板。

1. 在聊天面板中，描述您希望同事做什么。

   下表列出了示例提示。

   | 提示 | 同事的作用 |
   | --- | --- |
   | _按页面显示上个月_&#x200B;的会话 | 添加新的自由格式面板，其中包含您指定的维度、量度和日期范围。 不会覆盖现有面板。 |
   | _按设备划分此表_ | 将划分添加到您引用的表中。 |
   | _在此表中添加与上个月的比较_ | 向引用的表添加比较列。 |
   | _将此面板的日期范围更改为上个月_ | 更新面板的日期范围。 |
   | _将此表更改为折线图_ | 更改面板的可视化图表类型。 |
   | _将此面板重命名为移动性能_ | 重命名面板。 |
   | _将移动用户区段应用到此面板_ | 将现有区段应用到面板。 同事不知道区段定义，因此请确认该区段包含您期望的内容。 |
   | _为来自加拿大的访客创建一个区段_ | 创建区段并将其添加到项目中。 刷新页面后，该区段会显示在组件列表中。 |
   | _复制加拿大访客区段并将其更改为来自墨西哥的访客_ | 使用更新的逻辑创建区段的副本并将其添加到项目中。 |
   | _创建过去6周的日期范围_ | 创建日期范围。 日期范围会显示在组件列表中，而不进行刷新。 |
   | _为每个会话创建收入的计算量度_ | 创建计算量度。 同事可以创建简单的计算量度。 |
   | _向此面板添加说明，以解释访问次数下降_ | 将说明添加到面板。 |
   | _添加包含关键见解的文本可视化图表_ | 添加包含项目见解的文本可视化图表。 |
   | _创建一个项目，该项目包含流量、转化和收入面板_ | 创建一个项目，其中为您描述的每个区域创建一个面板。 |
   | _复制此项目并针对EMEA地区进行调整_ | 创建项目副本，并根据您指定的区域对其进行调整。 |
   | _保存项目_ | 保存项目。 |
   | _撤消您添加的细分_ | 撤消您指定的更改。 |
   | _删除旧面板_ | 列出它计划删除的面板，并等待您的确认后再删除它们。 |

1. 查看同事对项目所做的更改。 有关详细信息，请参阅[验证同事结果](#verify-coworker-results)。

### 提出有关项目的问题

当您就某个项目提出问题时，同事会在聊天面板中回答。 这包括&#x200B;_explain_、_summary_、_discush_&#x200B;和&#x200B;_告诉我更多_&#x200B;等请求。 根本原因分析和类似技能得出的结果也会保留在聊天面板中，直到您要求同事将它们添加到项目中。

1. 在Customer Journey Analytics中，打开现有的Workspace项目或创建新项目。

1. 选择标题右上角的&#x200B;**同事**&#x200B;图标![询问同事](/help/assets/icons/coworker.svg)以打开同事聊天面板。

1. 在聊天面板中，描述您希望同事做什么。

   下表列出了示例提示。

   | 提示 | 同事的作用 |
   | --- | --- |
   | _总结此项目_ | 在聊天面板中提供摘要，并提供将它作为文本可视化图表添加到项目中。 |
   | _在此项目中查找见解_ | 在聊天面板中提供见解并提供以将调查结果添加到项目。 |
   | _标记此面板中的任何异常_ | 描述聊天面板中的异常。 如果您要求同事在可视化图表上显示异常，则可能不会显示异常。 查看[当前限制](#current-limitations)。 |
   | _对移动访问量下降进行根本原因分析_ | 在聊天面板中提供分析，并提供将调查结果添加到项目中的功能。 |
   | _如何根据单元格值为其着色？_ | 介绍聊天面板中的步骤。 |
   | _说明跳出率量度_ | 介绍聊天面板中的组件。 说明不来自[数据字典](/help/components/data-dictionary/data-dictionary-overview.md)。 计划在将来的版本中支持数据字典定义。 |

1. 查看同事提供的答案。 有关详细信息，请参阅[验证同事结果](#verify-coworker-results)。

## 验证同事结果

同事帮助您检查其结果的准确性。 复习时请牢记以下几点：

* **同事显示其工作**：同事用于回答问题的区段、量度和过滤器已添加到项目中，以便您对其进行验证。

* **澄清问题**：当请求不明确或匹配多个组件时，同事会询问一个澄清问题或建议可供选择的选项。 例如，如果有多个指标与您使用的名称匹配，Co-worker会推荐匹配的指标。

* **数据质量说明**：同事在答案中包含数据质量说明。 例如，如果您将刚刚开始的一个月与刚刚开始的一个月进行比较，Co-worker会告诉您该比较基于局部数据。

## 当前限制

Co-worker的产品内体验具有以下限制：

* **区段定义**：当您按名称引用区段时，同事不知道该区段的定义。 同事可以根据区段的名称推断该区段包含的内容。 在依赖结果之前验证区段定义。

* **数据字典**：辅助进程未连接到[数据字典](/help/components/data-dictionary/data-dictionary-overview.md)。 它不能使用数据字典中的定义来解释量度和维度。

* **批准的组件**：同事未优先处理批准的组件，而不是类似的组件。

* **正在复制面板**：同事无法复制面板。

* **组件列表中的新区段**：在刷新页面之前，Co-worker创建的区段不会出现在左边栏的组件列表中。 同事创建的日期范围显示时不会进行刷新。

* **异常检测**：当您要求同事在可视化图表上显示异常时，可能不会显示异常。

* **对话历史记录**：为每个用户保存对话，而不是为项目保存对话。 打开项目的其他用户看不到您与同事的对话。 要与其他用户共享上下文，请将其添加到项目中各个面板的描述中。

* **多个浏览器选项卡**：如果您在多个浏览器选项卡中打开同一个对话，同事可能会失去对其工作内容的跟踪。

* **非英语语言**：在使用非英语语言的数据视图中，同事可能会在其响应中使用英语和数据视图语言的组合。
