# 常见问题解答

以下是有关归因的常见问题解答。

+++使用归因时，*无*&#x200B;行项是什么？

*无*&#x200B;行项目是一个全包项，它表示在回顾窗口内发生的不含任何接触点的所有转化。 要减少归因于&#x200B;*无*&#x200B;行项目的转化的次数，请尝试使用更长的回顾时间范围。

+++


+++归因模型在其他Analytics功能中是否可以使用？

是的。 归因模型也可用作数据视图中量度组件的组件设置的一部分。 请参阅[归因组件设置](/help/data-views/component-settings/attribution.md)。 对于维度组件，您可以使用持久性。 持久性表示给定的维度值能否在从中设置它的事件之外归因于指标。 它使用分配和有效期限的组合。 有关详细信息，请参阅[持久性组件设置](/help/data-views/component-settings/persistence.md)

+++


+++支持哪些维度和量度？

您在数据视图中定义的所有非标准量度都支持归因。

+++



+++归因是否适用于查找数据？

是，完全支持来自查找数据的维度。

+++
